Sơ đồ Cơ sở dữ liệu (ERD) - Dành cho báo cáo Word

Hướng dẫn: Đây là các sơ đồ ERD hoàn chỉnh đã được vẽ tự động bằng code Mermaid. Để đưa vào file Word của bạn:

  1. Nhấn tổ hợp phím Windows + Shift + S trên bàn phím.
  2. Kéo chuột để chụp lại từng hình sơ đồ bên dưới.
  3. Mở file Word lên và nhấn Ctrl + V để dán hình vào phần 3.7. Mô hình dữ liệu quan hệ.
