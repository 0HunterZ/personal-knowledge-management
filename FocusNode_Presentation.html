// Design Pattern: MVC + Service Locator

public class CoreSystem {

  public void initDB() {

    AppDataService service = isOffline ? new SqliteAppDataService() : new SqlAppDataService();

    ServiceLocator.setAppDataService(service);

  }

}

  • Polymorphic Architecture (Multi-DB): Seamlessly swap between SQLite (Local Offline) and SQL Server (LAN) via Service Locator.
  • Data Integrity: The CrashHandler system uses `Thread.UncaughtExceptionHandler` to automatically save drafts upon JVM exceptions.
  • JavaFX 21 + AtlantaFX: Separation of View (FXML) and Controller, optimizing UI with modern CSS.

LAN `P2P` Synchronization Core

// Cloud-independent group collaboration (5-10 machines) within local networks.

  • CRDTs (Conflict-free Replicated Data Type): Supports concurrent write operations, automatically merging data without conflicts.
  • Auto Discovery: `LanDiscoveryService` broadcasts DiscoveryPackets via UDP to automatically discover network nodes.

OS-Level Zen Mode { }

// Intervention to enforce absolute focus (OS-Level).

public void startZenMode() {

  Platform.runLater(() -> {

    osManager.setDoNotDisturb(true);

    networkRules.blockDistractingSites();

    audioService.playBinauralBeats();

  });

}

Breaking beyond standard apps: Calling Native APIs to hide OS notifications, block distracting websites, and play Binaural Beats to stimulate focus (Deep Work).
